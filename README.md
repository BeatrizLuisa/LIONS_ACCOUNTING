# LIONS ACCOUNTING
Formulário de Declaração de Imposto de Renda

## Descrição do Projeto
Este Formulário foi criado para facilitar a coleta de dados necessários para a Declaração de imposto de Renda, pensado para empresas de contabilidade, mas, também, sendo de grande ajuda para pessoas que fazem a declaração por conta própria.  

## Considerações
 Neste protejo, com os ensinamentos do Tech Educator, Felipe Aguiar, pude conhecer mais das funcionalidades do excel e como é uma ferramenta versátil e ainda necessária nos dias atuais. 
Tive um breve contato com VBA, navegação interativa, formatação de formas, e reforcei o aprendizado com funcionalidades já usadas anteriormente.
